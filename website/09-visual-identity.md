# Visual Identity

Version: 1.0

---

# Purpose

This document defines the visual identity used throughout the website.

The purpose is to ensure that visual changes are intentional, documented, and consistently applied during the study.

---

# Design Principles

The website should appear as a professional educational resource rather than a technology product.

Design priorities:

- clarity
- readability
- trustworthiness
- simplicity
- consistency

# Buttons

- navy background
- white text

Secondary:
- white background
- navy border

---

# Cards

Cards use:

- light surface background
- rounded corners
- thin border
- minimal shadow

---

# Imagery

Images should support the educational nature of the website.

Preferred themes include:

- notebooks
- writing
- books
- manuscripts
- libraries

Technology-themed illustrations should be avoided.

---

# Baseline Consistency

The baseline website uses the same visual identity.

Only the following elements may differ:

- domain name
- logo text
- article content

All other visual elements should remain identical unless documented otherwise.
