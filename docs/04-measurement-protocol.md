# Measurement Protocol

Version: 1.0

---

# Purpose

This document defines how measurements are collected, recorded, and maintained throughout the study.

The objective is to ensure that measurements are collected consistently over time and that the methodology remains transparent.

This document specifies *how* measurements are performed, not *how they are interpreted*.

---

# Measurement Principles

Measurements should be:

- repeatable
- documented
- timestamped
- traceable
- collected using consistent procedures whenever practical

Whenever the methodology changes, the change should be documented.

---

# Measurement Frequency

Measurements should be collected whenever practical.

The frequency may differ between metrics depending on:

- availability
- relevance
- research needs

Each measurement should include its collection date.

---

# Data Sources

The project may use multiple measurement sources.

Each recorded metric should identify its source whenever practical.

Examples may include:

- website analytics
- webmaster tools
- AI visibility tools
- internal project records

---

# Data Integrity

If measurements are corrected, replaced, or removed, the change should be documented.

Original observations should be preserved whenever practical.

---

# Missing Data

If a measurement cannot be collected, this should be recorded.

Missing observations should not be replaced with estimated values unless explicitly documented.

---

# Scope

This document defines how measurements are collected for this study.

Interpretation of measurements is documented separately in the discussion.
