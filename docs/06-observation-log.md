# Observation Log

Version: 1.0

---

# Purpose

This document records observations made throughout the study.

An observation is a factual record of something that occurred or was measured. This document intentionally avoids interpretation, explanation, or conclusions.

Its purpose is to preserve the evidence exactly as it was observed at the time of recording.

---

# Observation Principles

Observations should be:

- factual
- objective
- timestamped
- traceable
- based on documented evidence whenever possible

Interpretations belong in **08-discussion.md**, not in this document.

---

# Observation Record Template

Each observation should include the following information.

## Date

The date the observation was recorded.

## Observation ID

A unique identifier for the observation.

Example:

OBS-0001

---

## Source

The source of the observation.

Examples:

- Google Search Console
- Google Analytics
- ChatGPT
- Claude
- Gemini
- Targetlytics
- Manual observation

---

## Observation

A factual description of what was observed.

Example:

"The page was first indexed by Google."

---

## Supporting Evidence

Reference the relevant measurements, screenshots, reports, or datasets.

---

## Related Change

Reference the implementation activity, if applicable.

Example:

CHG-0012

---

## Notes

Optional factual notes.

Avoid interpretation.

# Scope

This document records observations only.

It does not explain why an observation occurred or whether it supports any research hypothesis.

Interpretation is documented separately.
